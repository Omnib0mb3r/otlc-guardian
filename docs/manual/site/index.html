OTLC Guardian · the manual · state of 2026-11-10 (1.5.0, unreleased)

Rules an agent reads. Checks it cannot talk its way past.

OTLC Guardian is a security floor for AI-assisted code. It ships the rules a coding agent reads at the start of a session, a static audit that checks a project before it is committed or deployed, a runtime scanner a project calls before and after every AI API call, and two Claude Code hooks that scan what an agent writes into files a later session will load as instructions. This manual explains each part as the code builds it today.

How to read this manual

Every claim here was checked against the source in C:\dev\Projects\otlc-guardian at commit 0fa32ce on 2026-11-10. Paths are relative to that repo unless they start with a drive letter. Where the code and a document (README, SETUP, SECURITY) disagree, the manual follows the code and says so. Where a part is planned and not built, it carries a planned tag. Where a writer could not confirm a detail from the code, the text says "needs check".

The manual moves with the code. Any change to how a part works edits the chapter that describes it, rebuilds the manual (node docs/manual/build.mjs) and republishes it in the same piece of work. The build fails on an em or en dash and on a link to an id that does not exist.
